# Beginner Level – Vrinda Store Sales Analysis

## 📌 Project Overview

This project is part of the Beginner Level of the Data Analytics Internship.

The objective of this project is to analyze the sales performance of Vrinda Store using Excel and create an interactive dashboard to identify important sales and customer trends.

The project covers data cleaning, basic data analysis, visualization, and dashboard creation.
